# ProGuide – Platform to Connect with Professionals

## 📌 Project Description

ProGuide is a web-based platform designed to connect students and users with verified professionals for mentorship, career guidance, and consultation services.

The platform provides structured appointment booking, profile management, review system, and admin verification to ensure trust and reliability.

---

## 🎯 Project Objectives

- Create a centralized professional guidance platform
- Enable secure user authentication with role-based access
- Provide systematic appointment booking
- Prevent double-booking conflicts
- Implement review and rating system
- Allow admin verification of professionals

---

## 🛠️ Tech Stack

Frontend: React.js  
Backend: Node.js
Database: MySQL  
Authentication: JWT (JSON Web Token)  
Email Service: Nodemailer  
Version Control: Git & GitHub  

---

## 🧩 System Modules

### 1️⃣ User Module
- Registration & Login
- Search professionals
- Book appointments
- Provide reviews

### 2️⃣ Professional Module
- Profile setup
- Set availability
- Manage bookings
- Track appointment history

### 3️⃣ Admin Module
- Verify professionals
- Manage users
- Monitor system activity
